# Aeterna IaC Foundry

**Stop writing modules. Start writing inputs.**

A consistent approach to IaC modules. Every repository here is a ready-made module or lookup for one resource or data source, generated from the provider itself, for Terragrunt, OpenTofu and Terraform.

Each module takes one map and returns its outputs as maps, so a single unit creates one resource or many. The shape is the same across all 35 providers we support. Learn one and you have learned them all!

## Get started

- [Quickstart](https://github.com/AeternaGroup/foundry-quickstart): two Terragrunt units running on Docker in a few minutes
- [Catalogue](https://aeternaltd.net/foundry/catalogue): find the module / lookup you need
- [Docs](https://aeternaltd.net/foundry/docs): how modules, lookups and versions work

## Editions

This organisation is the Public edition. It is free and open source, and gets new provider versions 90 days after we publish them.

The [Private edition](https://aeternaltd.net/foundry/pricing) gets them the day we publish, delivered into your own GitHub organisation, and includes [packages](https://aeternaltd.net/foundry/docs/packages).
